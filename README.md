# sysadmin-usb

Портативный инструментарий системного администратора.
Работает с флешки на Windows и Linux.

## Возможности

- 🖨️ **Принтеры:** мониторинг, автопочинка, отчёты
- 🌐 **Сеть:** сканирование, карта, диагностика
- 👤 **Active Directory:** пользователи, аудит, пароли
- 💾 **Резервное копирование:** создание, проверка, восстановление
- 🖥️ **Система:** информация, очистка, обновления
- 📊 **Отчёты:** генерация, экспорт

## Быстрый старт

### Windows
1. Вставь флешку.
2. Двойной клик на `start.bat`.

### Linux
1. Вставь флешку.
2. Открой терминал в папке проекта.
3. Выполни: `./start.sh`
