## 📖 О проекте

**sysadmin-usb** — это набор инструментов для повседневной работы системного администратора.
Приложение запускается **с флешки**, работает **без установки**, поддерживает **Windows и Linux**,
и имеет **два интерфейса** — консольный и веб.

**Автор:** Чернов Александр Дмитриевич

### 🎯 Зачем это нужно

В работе сисадмина постоянно нужно:
- Диагностировать ПК (что сломалось, где проблема)
- Мониторить принтеры (тонер, статус, ошибки)
- Сканировать сеть (кто в сети, какие устройства)
- Делать бэкапы (данные, система)
- Проверять Active Directory (пользователи, пароли)
- Генерировать отчёты (для руководителя)

**sysadmin-usb** — всё это в одном приложении. Вставил флешку, запустил — и у тебя полный набор инструментов.

## 🚀 Возможности

### 🖨️ Принтеры

| Функция | Что делает |
|---------|-----------|
| **Мониторинг** | Опрос принтеров по SNMP (тонер, статус, страницы) |
| **Автопочинка** | Перезапуск службы печати, очистка очереди |
| **Сканер сети** | Автопоиск сетевых принтеров (SNMP) |
| **Локальные принтеры** | Поиск USB-принтеров (Windows/Linux) |
| **Отчёты** | История опросов, экспорт |

### 🌐 Сеть

| Функция | Что делает |
|---------|-----------|
| **Диагностика** | ping, tracert, DNS, проверка портов, HTTP |
| **Сканирование подсети** | Поиск всех устройств (nmap + ping) |
| **Карта сети** | Интерактивная визуализация (HTML) |
| **Сканирование портов** | Открытые порты + анализ безопасности |

### 🖥️ Система

| Функция | Что делает |
|---------|-----------|
| **Health Check** | 13 проверок: железо, RAM, диски, сеть, службы, драйверы, USB, события, процессы, безопасность, питание |
| **Информация о ПК** | ОС, CPU, RAM, диски, uptime |
| **Очистка** | Удаление временных файлов |
| **Обновления** | Проверка обновлений системы |

### 💾 Резервное копирование

| Функция | Что делает |
|---------|-----------|
| **Создать бэкап** | 4 профиля: workstation, full_home, system, server |
| **Полный образ диска** | 🔴 dd + gzip (с красными предупреждениями) |
| **Проверить бэкап** | Целостность + тестовое восстановление |
| **Восстановить** | Распаковка архива |
| **Список бэкапов** | Все архивы с датами и размерами |

### 👤 Active Directory

| Функция | Что делает |
|---------|-----------|
| **Пользователи** | Список, поиск, разблокировка |
| **Аудит AD** | Отключённые, неактивные >90 дней |
| **Аудит паролей** | Старые, неистекающие, никогда не менявшиеся |

### 📊 Отчёты

| Функция | Что делает |
|---------|-----------|
| **Сгенерировать отчёт** | Общий отчёт (система + health + принтеры + бэкапы + сеть) |
| **Экспорт** | Markdown → HTML, JSON → CSV |
| **История** | Все отчёты с датами |

## 💻 Установка

### Требования

- **Python 3.10+**
- **Linux** (Ubuntu/Debian/Mint) или **Windows 10/11**
- **nmap** (для сканирования сети): `sudo apt install nmap`

### Linux

```bash
# 1. Клонировать репозиторий
git clone https://github.com/Ostenvrn/sysadmin-usb-flash-toolbox.git
cd sysadmin-usb-flash-toolbox

# 2. Создать виртуальное окружение
python3 -m venv .venv
source .venv/bin/activate

# 3. Установить зависимости в libs/
pip install --target=libs/ -r requirements.txt

# 4. Запустить
chmod +x start.sh
./start.sh


### Windows

REM 1. Клонировать репозиторий
git clone https://github.com/Ostenvrn/sysadmin-usb-flash-toolbox.git
cd sysadmin-usb-flash-toolbox

REM 2. Запустить
start.bat

### Настройка (опционально)

# Скопировать шаблон
cp .env.example .env

# Отредактировать .env (AD, Telegram, БД)
nano .env

### Запуск 
./start.sh
